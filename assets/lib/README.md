# Libraries Directory

This directory contains third-party libraries and frameworks.

## Common Libraries for Web Projects:

### CSS Frameworks:
- **Bootstrap**: `bootstrap.min.css`
- **Tailwind CSS**: `tailwind.min.css`
- **Bulma**: `bulma.min.css`

### JavaScript Libraries:
- **jQuery**: `jquery.min.js`
- **Chart.js**: `chart.min.js`
- **AOS (Animate On Scroll)**: `aos.min.js`
- **Swiper**: `swiper.min.js`

### Icon Libraries:
- **Font Awesome**: `fontawesome.min.css`
- **Material Icons**: `material-icons.css`
- **Feather Icons**: `feather.min.js`

## Usage Guidelines:
1. Always use minified versions in production
2. Include source maps for development
3. Check for updates regularly
4. Verify licenses before use
5. Consider using CDN links instead of local files

## CDN Alternative:
Instead of downloading libraries, you can use CDN links in your HTML:
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js"></script>
```
