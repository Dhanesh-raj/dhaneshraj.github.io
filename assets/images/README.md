# Images Directory

This directory contains all image assets for the GitHub profile project.

## Recommended Images:
- Profile photos
- Research diagrams
- Project screenshots
- Custom icons
- Background images

## Supported Formats:
- PNG (recommended for icons and graphics)
- JPG/JPEG (for photos)
- SVG (for scalable graphics)
- WebP (for optimized web images)

## Naming Convention:
- Use lowercase with hyphens: `profile-photo.png`
- Be descriptive: `research-diagram-neural-networks.svg`
- Include dimensions for multiple sizes: `logo-32x32.png`, `logo-64x64.png`
